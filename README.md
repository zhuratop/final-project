# Проект по анализу данных нобелевских лауреатов

Проект по анализу данных о лауреатах Нобелевской премии.
Цель — из вложенного JSON, который отдаёт публичное API Nobel Prize, собрать удобную плоскую структуру и сделать первичный EDA.

## В проекте есть:

парсер/процессор JSON: функции extract_nested_value, process_dictionary_with_config, process_list_of_dicts_with_config, create_processor — позволяют по конфигам вытаскивать нужные поля из вложенных словарей (как для людей, так и для организаций);

## Конфиги для трёх сущностей:
приз (CONFIG_PRIZE),
лауреат-человек (CONFIG_PERSON),
лауреат-организация (CONFIG_ORG);

## классификация лауреатов: функции is_person и is_org определяют тип записи и применяют нужный конфиг;

## EDA-функции: подсчёт количества записей, пропусков по полям, сбор всех призов, поиск дубликатов и “дыр” в id, расчёт min/max id;

## функции для группировки и агрегаций (аналог mini-pandas): group_by_attributes, apply_aggregation_to_groups, агрегаторы (mean, median, top-N);

## анализ по странам и категориям: топ стран по числу лауреатов, топ стран внутри каждой категории;

## анализ возраста: расчёт возраста лауреатов при первом награждении и построение распределений с помощью matplotlib.

## Проект рассчитан на “чистый” Python — без pandas и numpy — и показывает, как построить пайплайн предобработки и EDA на стандартной библиотеке.
